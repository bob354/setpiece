Abstract

Agents built on large language models (LLMs) can build interactive 3D scenes from a request, so the user's work shifts from writing code to checking and correcting it. However, a user who does not read the code can often only correct the agents by asking again and waiting for the agents once more.

We demonstrate SetPiece, a desktop and virtual reality (VR) authoring system that shows the agents' work in two editable forms. Before objects are generated, the agents propose a layout plan of labeled 3D boxes that the user can move, rotate, scale, and select. Once a behavior is generated, it appears as a node (in VR, as a panel) whose objects and parameters the user can edit by hand. Generated code is loaded at runtime, so edits take effect without restarting the application, and failing code is rolled back.

SetPiece also includes built-in tasks with automatic checks to compare agent pipeline configurations. Planned user studies will examine when users fix errors by hand and when they still need agents or code, thereby assessing whether editable intermediate representations allow people without game-engine experience to steer coding agents.
